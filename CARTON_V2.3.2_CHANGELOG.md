# SC Barcodezy Official V2.3.2 — Carton Production Update

Baseline: SCBarcodezyOfficial_V2.3.1_Carton_Studio_Fully_Package.zip. Carton Studio only.

## Changes
1. Interactive bounding box with 8 screen-sized handles, aspect ratio preserved on all handles, anchored resize, dimensions synchronized in mm, constrained to the current panel. Selection handles are not exported. Numeric width control remains.
2. Full-width 2D workbench, collapsible tool area above it, independently scrolling tool groups on desktop, responsive mobile layout, fit/zoom/pan controls, margin around dieline. 3D proof and export panels below.
3. Mandatory Helvetica Bold outlined SIZE label on lower left flap scaled to 130% of V2.3.1 (120 → 156 mm cap; width/height fractions 60 → 78%); still constrained to the usable flap.
4. Country selector CHINA, INDIA, KOREA, THAILAND, LAO, existing countries and custom uppercase country. Verify legal country marking against actual origin before release.
5. Standard Symbol Set: stacking / keep dry / up arrow, horizontally aligned, 35 mm each + 5 mm gaps by default (subject to panel fit). Editable stack count and gap, group move/resize/rotate/duplicate; ungroup into three individual assets; regroup the original three when on the same panel, restoring aligned layout and saved gap ratio and rotation. Standalone symbols unchanged.
6. PDF printing output now always uses explicit DeviceCMYK (process or K-only) or named PDF Separation (one spot ink; CMYK alternate). Default K-only. RGB proofs in SVG/JPEG are explicitly not production PDFs. Black artwork maps to K100, tones to K-only tints. Spot name and proof color editable. No structural guides or kraft background in printing master.
7. Production ZIP: complete artwork proof, printing master, separate dieline, preflight text; CMYK includes C/M/Y/K grayscale-positive K-channel proofs for inspection. RIP final plates should be generated from printing master; do not use the channel proofs as independently certified printing plates. All pages share physical coordinates and page size.
8. Color preflight checks image readiness, spot naming, raster resolution and conversion acknowledgement. Supported simple SVG/standard artwork/barcodes stay vector. Native PDF components and complex SVG/raster assets are rendered to CMYK or spot image data with alpha as needed; original native PDF vectors/spot definitions are not preserved in this production conversion. Target 600 ppi subject to 8192-pixel edge and 16M-pixel image caps. Low-resolution assets do not gain original detail by resampling. RGB-to-CMYK is mathematical, not ICC-profile-managed; no PDF/X certification, trapping, or verified overprint behavior. Confirm color, substrate, origin, stacking, and physical output with supplier.

## Validation performed
- Chromium integration harness with exact local HTML/CSS/scripts and lazy bundled PDF dependencies injected (hosting navigation not tested). No page errors in tested flows.
- Initial automatic SIZE width 156 mm; eight selection handles; real pointer SE resize from 115 mm to 142.65 mm; standard set count, spacing, 90° rotate, ungroup/regroup; all five requested countries and custom country; drag/drop SVG and PNG; full-width tool and workspace widths both 1382.4 CSS px at 1440 px viewport.
- Exported K-only, custom spot and process CMYK PDFs; page size 1435 × 550 mm (4067.72 × 1559.06 pt); 40 vector drawing objects in each standard-only test. CMYK production ZIP contained 8 files with identical PDF page dimensions; dieline has two drawing paths. Mixed red vector and green PNG exported as DeviceCMYK, raster image present.
- Ghostscript tiffsep test: standard-artwork K-only PDF had nonempty K and blank C/M/Y; custom spot PDF had nonempty named Custom Red and blank C/M/Y/K. Mixed CMYK PDF rendered nonempty C/M/Y/K separations. Output proofs inspected with PyMuPDF. This is a software separation test, not a factory RIP or press test.
- Native PDF import/extraction UI and conversion were not exercised in this test; non-Carton modules retained byte-for-byte, not re-tested end-to-end. No hosting/deployment or physical print validation. SVG/JPEG proof output not re-tested in this run.
