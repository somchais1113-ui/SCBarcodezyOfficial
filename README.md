## นำเข้า SVG/PDF ตามขนาดจริง

ลากไฟล์ลงในช่อง **วางหรือเลือกไฟล์ฉลาก** หรือคลิกเพื่อเลือก Studio จะใส่ความกว้างและความสูงเป็นมิลลิเมตร พร้อมแสดงที่มาของขนาดใต้ช่องวางไฟล์

- PDF ใช้ TrimBox เมื่อมีกรอบหลังตัดที่อยู่ภายในหน้าที่แสดง หากไม่มีจะใช้หน้าที่มองเห็นตาม CropBox หรือ MediaBox ระบบคำนวณตามการหมุนหน้าและ UserUnit ไฟล์หลายหน้าเลือกนำเข้าทีละหน้า
- SVG อ่านความกว้างและสูงที่ระบุบนองค์ประกอบราก รองรับ mm, cm, in, pt, pc, Q รวมถึง px และตัวเลขที่ไม่มีหน่วยที่ 96 px ต่อนิ้ว ถ้ามีเพียง viewBox จะใช้ความกว้างปัจจุบันใน Studio ประกอบกับสัดส่วนของไฟล์ กรณีนี้ให้ใส่ความกว้างพิมพ์จริงก่อนถอดแบบ ความสูงจะปรับตาม
- ต้นฉบับ PDF และ SVG ถูกเรนเดอร์ในเครื่องเป็นภาพอ้างอิงสำหรับ OCR ที่ขนาดกายภาพของหน้า เลเยอร์ที่แก้ข้อความได้เกิดจากขั้นตอนถอดแบบ ความละเอียดภาพอ้างอิงตั้งเป้า 600 ppi และลดลงสำหรับหน้าขนาดใหญ่ โดยแสดงค่าที่ใช้ใต้ช่องวางไฟล์
- SVG ที่มีภาพลิงก์ภายนอกให้ Embed ก่อนนำเข้า สำหรับ PDF ที่ต้องใช้รหัสผ่านให้ใช้สำเนาที่ปลดล็อก

## จัดสระและไม้โทใน Template Studio

เลือกข้อความบน Canvas แล้วเปิดดู **ขยับเครื่องหมายไทย** ใต้ช่องขนาดฟอนต์ ภาพขยายแสดงเครื่องหมายที่กำลังปรับด้วยสีน้ำเงิน

- แตะเครื่องหมายในภาพขยาย หรือเลือก **สระบน / ไม้ไต่คู้**, **ไม้โท** หรือ **วงกลมของ ำ** จากรายการ เลือกระยะแล้วกดลูกศรซ้าย ขวา ขึ้น หรือลง ครั้งละ 0.05, 0.10, 0.25 หรือ 0.50 pt ปุ่ม **คืนตำแหน่งที่เลือก** จะล้างเฉพาะระยะที่ปรับในตัวเลือกนั้น
- ในคำ “ข้อแนะนำ” เลือกไม้โทเพื่อขยับไม้โทบน ข เลือกวงกลมของ ำ เพื่อขยับวงกลมเหนือ น โดยยังวางส่วน า บนแนวฐานเดิม
- ถ้ามีเครื่องหมายชนิดเดียวกันหลายจุด ให้เลือกทุกจุดหรือระบุจุดที่ต้องการ ค่าทุกจุดจะใช้ต่อเมื่อเปลี่ยนเนื้อหา ค่ารายจุดจะใช้เฉพาะเมื่อข้อความตรงกับชุดที่ปรับไว้ ทั้งสองค่าบวกกันและบันทึกกับ Template หากต้องการยกหรือลดเครื่องหมายบนทั้งบรรทัด ให้ใช้ค่าเดิมใน **ปรับตัวอักษรละเอียด → ลดเครื่องหมายบนทั้งหมด (pt)**
- **Undo** ใช้ ⌘Z บน Mac หรือ Ctrl+Z บน Windows **Redo** ใช้ ⌘⇧Z หรือ Ctrl+Shift+Z และบน Windows ใช้ Ctrl+Y ได้ด้วย เมื่อเคอร์เซอร์อยู่ในช่องพิมพ์ จะย้อนการพิมพ์ภายในช่องนั้น
- ใช้ปุ่ม **− / +** เหนือ Canvas หรือเลือกเปอร์เซ็นต์ตั้งแต่ 25% ถึง 800% โดย 100% คือพอดีกับความกว้างพื้นที่ทำงาน การซูมใช้สำหรับตรวจภาพบนจอ

## ส่งฉลากเข้า Illustrator และส่งโรงพิมพ์

**เทียบฟอนต์หนึ่งครั้งต่อช่อง** ก่อนเปลี่ยนชื่อสินค้า เลือกคำเดิม เปิด “เทียบฟอนต์กับภาพต้นฉบับ” แล้วเลือกฟอนต์ที่ใช้จริง Studio มี DB ThaiText X Regular รวมอยู่แล้ว ระบบเทียบรูปอักษรกับคำเดิมเพื่อหาขนาด สเกลแนวนอน ช่องไฟ และแนวฐาน เมื่อแก้ข้อความหรือเปิด Template อีกครั้ง ระบบจะใช้ค่าที่บันทึกไว้ ใช้ “ซ้อนต้นฉบับ” เพื่อตรวจตำแหน่งสระและวรรณยุกต์ และใช้ “ตัวอย่างก่อนส่งออก” เพื่อดูเส้นที่จะใช้พิมพ์

- **เก็บทรงอักษรเดิมเป็นเส้น** เป็นค่าเริ่มต้นสำหรับงานถอดจากภาพ ช่อง OCR ที่คงรูปต้นฉบับจะได้เส้นตามขอบหมึกของภาพ ข้อความที่แก้จะได้เส้นจากฟอนต์ที่ใช้ สำหรับช่องจำนวนที่มีช่องว่างแยกหน่วยชัด เช่น “12 ด้าม /โหล” การแก้เฉพาะจำนวนจะเก็บรูปหน่วยเดิมได้ รายละเอียดที่อยู่รวมกับโลโก้หรือภาพพื้นจะยังเป็นส่วนของภาพนั้น
- **Create Outlines จากฟอนต์ทุกช่องข้อความ** ใช้เส้นจากไฟล์ฟอนต์ของทุกช่องที่แก้ไขเป็นข้อความได้ เหมาะเมื่อทราบฟอนต์และน้ำหนักของต้นฉบับ เลเยอร์ที่ผู้ใช้ตั้งเป็นภาพข้อความคงที่จะใช้เส้นตามขอบหมึก
- **SVG และ PDF** มีเส้นอักษรและภาพฝังในไฟล์เดียว PDF เก็บภาพราสเตอร์อย่างน้อย 600 ppi ที่ขนาดวางจริง และเก็บจำนวนพิกเซลเดิมเมื่อสูงกว่าเกณฑ์ หากต้นทางมีพิกเซลต่ำ ระบบจะแสดงความละเอียดต้นทางหลังส่งออก เลือกเลเยอร์ส่วนภาพ แล้วกด “แทนที่ด้วยไฟล์โลโก้ความละเอียดสูง” เพื่อฝังภาพที่ละเอียดกว่าในกรอบเดิม
- **PNG และ JPG** ใช้ขนาดฉลากเป็นมิลลิเมตรเพื่อคำนวณพิกเซลที่ 600 dpi และบันทึกค่าความละเอียดในไฟล์ JPG ใช้พื้นขาว ส่วน PNG เก็บพื้นโปร่งใสในบริเวณที่ไม่มีวัตถุหรือภาพพื้น
- บันทึก **Template** เพื่อกลับมาแก้ข้อความ ส่วน SVG และ PDF เป็นไฟล์ปลายทางสำหรับผลิต มีไฟล์ตัวอย่างให้เปิดตรวจตรงในโฟลเดอร์ `examples/LUNA-outlined.svg` และ `examples/LUNA-print.pdf`

## จัดฉลากหลายสินค้าลง A4 ขนาดจริง

ตั้งความกว้างและสูงของฉลากเป็นมิลลิเมตร แก้สินค้าแรก ระบุจำนวนดวง แล้วกด **เพิ่มลง A4** ทำซ้ำกับสินค้าถัดไป โปรแกรมเก็บข้อความ บาร์โค้ด ภาพ และฟอนต์แยกตามแต่ละแบบ เปิด **ดูแผ่น A4** เพื่อตรวจแผ่น ปรับจำนวน หรือเลือกดวงแล้วเปลี่ยนตำแหน่ง X/Y กด **แก้ข้อความและบาร์โค้ด** เพื่อปรับทุกดวงของแบบที่เลือก แล้วกด **ใช้กับฉลากแบบนี้บน A4** เพื่อกลับมาดูผล

PDF ใช้ A4 แนวตั้ง 210 × 297 มม. เว้นขอบ 5 มม. และช่องระหว่างฉลากอย่างน้อย 3 มม. ระบบขึ้นแผ่นใหม่เมื่อวางต่อในแผ่นเดิมไม่ได้ รองรับฉลากไม่เกิน 200 × 287 มม. ต่อดวง เมื่อกด **ส่งออก PDF ขนาดจริง** ชื่อไฟล์มาจากสินค้าแบบแรกที่อยู่ในรายการและวันที่ตามเวลาไทย เลือก **Actual size / 100%** ในหน้าพิมพ์ รายการบน A4 อยู่ในแท็บปัจจุบันจนกว่าจะรีโหลดหรือปิดแท็บ หากต้องการเก็บต้นแบบไว้แก้ครั้งหน้า ให้ใช้ **บันทึก Template** ในพื้นที่แก้ไข

ชื่อไฟล์ SVG, PDF, PNG, JPG และไฟล์สำรอง Template ใช้ชื่อสินค้าบนฉลาก ตามด้วยวันที่ส่งออกตามเวลาไทยในรูปแบบ `ชื่อสินค้า_YYYY-MM-DD` โดยใช้ปี ค.ศ. ตัวอย่าง `ปากกา LUNA_2026-11-19.svg` สำหรับ Batch โปรแกรมใช้ชื่อสินค้าจากหน้าแรกของ PDF หากต้องการระบุช่องเอง ให้เลือกเลเยอร์ข้อความ แล้วกด **จัดการเลเยอร์และข้อมูล Batch → ใช้ข้อความช่องนี้เป็นชื่อไฟล์**

ขณะถอดแบบ Canvas จะแสดงภาพต้นฉบับพร้อมเส้นสแกนและขั้นตอนการทำงาน หากเปิด Reduce Motion ในระบบ จะแสดงเฉพาะสถานะ

- บาร์โค้ดในตัวอย่างเก็บเลข EAN-13 หนึ่งค่า เมื่อเปลี่ยนเลขที่ถูกต้อง แท่งและเลขด้านล่างจะเปลี่ยนพร้อมกัน

- ช่องที่ผูก Batch ไว้ในตัวอย่างเลือกใช้เฉพาะคอลัมน์ที่ต้องการได้ เช่น `Price`, `Pack`, `Size`, `GTIN` หรือ `ProductNameTH` หัวคอลัมน์ที่ข้ามใช้ค่าปัจจุบันจากฉลาก

## ถอดภาพของคุณ

เลือก **คงภาพต้นฉบับ แก้เฉพาะช่อง** สำหรับงานผสมข้อความและกราฟิก ระบบพยายามแบ่งข้อความตามช่อง จับบาร์โค้ดและ QR และเก็บรายละเอียดที่ไม่ได้แยกไว้ในภาพพื้น ภาพ LUNA ไฟล์เดียวกับตัวอย่างจะเปิดช่องที่ตรวจเทียบไว้แล้ว ภาพอื่นผ่านการอ่าน OCR และอาจต้องตรวจคำหรือปรับขอบเขต โดยเฉพาะภาพที่มีสระวรรณยุกต์ชิดกัน

หาก OCR อ่านคำผิด ให้เลือก **เทียบฟอนต์กับภาพต้นฉบับ → แก้คำถอด OCR โดยคงรูปอักษรเดิม** เพื่อบันทึกคำที่ถูก ถ้าต้องการเปลี่ยนเนื้อหาบนฉลาก ให้พิมพ์ในช่อง “ข้อความ” โดยตรง

ใช้ **ตีกรอบช่องข้อความจากภาพ** กับส่วนของภาพพื้นที่ยังไม่ได้แยก ถ้าต้องการกำหนดกรอบเองทั้งงาน เลือก “คงภาพและตีกรอบช่องเอง” ก่อนถอดแบบ ลากชิดข้อความรวมสระและวรรณยุกต์ โหมดคงภาพเหมาะกับพื้นสีเรียบ บนภาพถ่ายหรือพื้นไล่สี ส่วนที่เปิดออกหลังลบตัวอักษรใช้สีประมาณจากขอบกรอบ

เมื่อต้องการสร้างข้อความและเส้นเวกเตอร์ใหม่ทั้งฉลาก ให้เลือก **สร้างเลเยอร์เวกเตอร์จาก OCR** ก่อนถอดภาพ

**เทียบฟอนต์จากต้นฉบับ** ในแถบต้นฉบับและการถอดแบบ กด **เพิ่มฟอนต์ต้นฉบับ** แล้วเลือก OTF หรือ TTF ของน้ำหนักที่ใช้บนฉลาก เลือกพร้อมกันได้หลายไฟล์ หากใช้ PraJad, PraJad Bold หรือ Angsana Bold ใช้ชุดที่ให้มาได้เลย ฟอนต์ที่เพิ่มจะเก็บกับ Template และติดไปในไฟล์สำรองโปรเจกต์ JSON

หลังถอดภาพ ระบบนำข้อความแต่ละบรรทัดไปวาดด้วยฟอนต์ที่มี แล้วเทียบรูปอักษร สัดส่วน และช่องไฟกับภาพจริง คลิกบรรทัดบนฉลากเพื่อแก้คำ ในหัวข้อ **เทียบฟอนต์กับภาพต้นฉบับ** เลือกตัวอย่างเพื่อนำฟอนต์และช่องไฟที่เทียบได้มาใช้ คะแนน 0–100 ใช้จัดอันดับความคล้ายของภาพภายในบรรทัดเดียว บรรทัดสั้น ภาพเบลอ และคำที่ OCR อ่านผิดอาจทำให้หลายฟอนต์ได้คะแนนใกล้กัน ถ้าแก้ข้อความ OCR ให้ตรงก่อน ตัวอย่างฟอนต์จะคำนวณใหม่เมื่อออกจากช่องข้อความ

**บรรทัดคงที่ที่ต้องเหมือนภาพเดิม** เลือก “ใช้ภาพต้นฉบับสำหรับบรรทัดคงที่” เพื่อใช้พิกเซลเดิมรวมพื้นหลังในกรอบนั้น ขนาดขยายขึ้นอยู่กับความละเอียดของต้นฉบับ สลับกลับเป็นข้อความได้โดยยังเก็บฟอนต์และค่าที่แก้ไว้ สำหรับชื่อสินค้าและข้อมูลที่เปลี่ยนตามแถวใน Batch ให้ใช้เลเยอร์ข้อความ

**พื้นที่ทำงาน** ปรับมุมมองได้จากแถบเหนือฉลาก เลือกซ้อนต้นฉบับหรือดูความต่าง ขยายพื้นที่เต็มความกว้าง และซูมได้ถึง 400% เลือกเลเยอร์จากภาพ รายการใต้ภาพ หรือเมนูด้านบนแผงแก้ไข ช่องแก้ข้อความแสดงผลบนฉลากขณะพิมพ์ ส่วน Tracking, Kerning, Baseline และสเกลอยู่ใน “ปรับตัวอักษรละเอียด”

**ทดลองรอบแรก** ลาก `examples/reference-80x34.jpg` ลงในช่องต้นฉบับ กำหนด 80 × 34 mm แล้วกดถอดภาพ ภาษาไทย/อังกฤษใช้โมเดล OCR บนเครื่อง ไม่ต้องใช้ API key หรือเริ่มเซิร์ฟเวอร์ เลี่ยงการหมุนเอียงและครอปภาพให้ตรงขอบงานจริงก่อนนำเข้า

1. ดูผลในโหมดซ้อนต้นฉบับ ปรับความทึบหรือใช้ดูความต่าง เลือกแต่ละเลเยอร์จากรายการหรือบนฉลาก ตรวจข้อความทุกบรรทัดและเลขบาร์โค้ด โดยเฉพาะสระ วรรณยุกต์ และตัวอักษรคล้ายกัน ระบบประมาณขนาดและตำแหน่งจากภาพ ความถูกต้องของฟอนต์ขึ้นกับการเลือกไฟล์ฟอนต์จริง
2. แก้ Character ในแผงขวา Tracking และ Kerning ใช้หน่วย 1/1000 em โดย Kerning รุ่นนี้ปรับหนึ่งคู่ต่อเลเยอร์ เลือกตำแหน่งหลังกลุ่มอักษรเพื่อรักษาสระและวรรณยุกต์ นำเข้าฟอนต์ OTF/TTF ของน้ำหนักที่ต้องการได้
3. ลากเลเยอร์หรือระบุ X/Y กดลูกศรบนพื้นที่ฉลากเพื่อขยับ 0.1 mm หรือ Shift + ลูกศรเพื่อขยับ 1 mm เลเยอร์ที่ใช้ชื่อกลุ่มเดียวกันจะเลื่อนตามกันเมื่อไม่ได้ล็อก
4. ช่องคำสั่งรองรับเลื่อนซ้าย/ขวา/ขึ้น/ลง จัดกึ่งกลางแนวนอน หมุน ขนาดฟอนต์ ช่องไฟ ระยะบรรทัด ยกหรือลดเส้นฐาน สเกลแนวนอน/แนวตั้ง และ Kerning ของคู่ที่ระบุ เช่น “เลื่อนลง 0.5 mm และ ขนาด 9 pt” ตรวจค่าก่อน–หลังแล้วกดยืนยัน
5. OCR แยกข้อความและเส้นตรง และพยายามอ่านบาร์โค้ดแนวนอน EAN-13/ITF-14 หนึ่งสัญลักษณ์ต่อภาพ ส่วนที่อ่านไม่ออกให้เทียบต้นฉบับแล้วเพิ่มเอง สำหรับโลโก้ให้เพิ่ม “ส่วนภาพ / โลโก้” กำหนด X/Y/W/H ให้ตรงตำแหน่งแล้วกด “ตัดภาพจากตำแหน่งนี้”
6. เครื่องหมาย ◇ ใช้ติดตามการตรวจคำถอด จะกดส่งออก SVG, Supplier PDF หรือ PDF หลายแถวได้ทันที หากต้องการเก็บสถานะของเลเยอร์ให้เลือก “ทำเครื่องหมายว่าตรวจแล้ว” ในหัวข้อจัดการเลเยอร์และข้อมูล Batch บันทึก Template ในเบราว์เซอร์เดิม หรือดาวน์โหลดโปรเจกต์ JSON เพื่อสำรองและเปิดข้ามเครื่อง โปรเจกต์รวมภาพ วัตถุ และฟอนต์ที่นำเข้า การบันทึกซ้ำอัปเดตแบบเดิม หากต้องการแยกแบบให้สร้างสำเนาก่อนบันทึก
7. ส่งออก SVG หรือ Supplier PDF ที่ขนาดฉลากจริง หากมีส่วนภาพ ผลลัพธ์จะคงส่วนนั้นเป็นภาพ Raster
8. สำหรับหลายสินค้า กำหนด “ชื่อคอลัมน์สำหรับ Batch” ที่เลเยอร์ข้อความหรือบาร์โค้ด วางตารางจาก Excel พร้อมหัวคอลัมน์ที่ตรงกัน แล้วสร้าง PDF หนึ่งฉลากต่อหน้า (สูงสุด 300 แถว)

OCR อาจรวมบางคำหรือแยกหนึ่งบรรทัดเป็นหลายเลเยอร์ โหมดเทียบภาพใช้สัดส่วนฉลากที่กรอก ผู้ใช้ต้องแก้และตรวจระยะก่อนส่งผลิต เครื่องมือถอดแบบรับ PNG/JPG/WebP และนำเข้า SVG/PDF เป็นภาพอ้างอิงที่ขนาดพิมพ์ของหน้า

**ส่วนประกอบใหม่** `studio.html` และ `assets/studio/` ใช้ Tesseract.js 5.1.1, โมเดลภาษา eng/tha, ZXing และตัวเข้ารหัสบาร์โค้ดจาก V1.1 ชุด worker ภายในแก้การเลือกชื่อภาษาจาก code เมื่อใช้โมเดลที่ฝังในแพ็กเกจ ตัว Editor และฟอนต์โหลดจากไฟล์ในโฟลเดอร์นี้

## สร้างใบเดียว

1. เลือก Level / โหมด
2. กรอก GTIN และข้อมูลสินค้า
3. EAN รับ 12 หลักเพื่อเติม Check Digit หรือ 13 หลักเพื่อตรวจสอบ
4. Lv2–Lv4 รับ GTIN-13 ที่ถูกต้อง ถ้า Manual ITF-14 ว่างจะคำนวณจาก GTIN และ Indicator
5. Manual ITF-14 ที่มีค่าจะใช้เลขนั้นเสมอ ต้องมี 14 หลักและ Check Digit ถูกต้อง ไม่คำนวณทับ ไม่บังคับให้เป็นเลขเดียวกับที่ derive จาก GTIN
6. แก้ข้อผิดพลาดก่อน Export; QTY ต้องเป็นจำนวนเต็มบวก, G.W. เป็นเลขไม่ติดลบหรือว่าง

ระบบยอมรับช่องว่างและขีดคั่นในรหัส แต่ปฏิเสธตัวอักษรและเลขแบบ Scientific notation
แนะนำตั้งคอลัมน์ GTIN ใน Excel เป็น Text เพื่อรักษาศูนย์นำหน้า

## Batch: กติกาการวางคอลัมน์

- ต้องมี GTIN อย่างน้อย 1 รายการ
- คอลัมน์ที่มี 1 ค่าใช้ซ้ำทุกใบ **รวม Manual ITF-14 หากกรอกค่าเดียวโดยเจตนา**
- คอลัมน์ที่มีหลายค่าต้องมีจำนวนแถวเท่ากับชุดข้อมูล จึงจะ Export ได้
- เก็บบรรทัดว่างภายในไว้ตามแถวเดิม ไม่เลื่อนข้อมูล
- ละ newline ปิดท้ายจากการ Copy หนึ่งตัว; หากต้องการค่าว่างชัดเจนใช้ `-` แทนเซลล์ว่างได้
- คอลัมน์อื่นที่ว่างทั้งหมดใช้ค่าจากฟอร์มใบเดียว
- **ข้อยกเว้น Manual ITF-14:** ว่างทั้งคอลัมน์หรือว่างเฉพาะแถว จะคำนวณจาก GTIN ของแถวนั้น ไม่ดึง Manual จากฟอร์มใบเดียว
- ใน EAN-13 TH/EN ใช้ช่องชื่อ EN และ TH ที่แสดงเฉพาะโหมดนี้
- คอลัมน์ที่ซ่อนอยู่ในโหมดอื่นไม่มีผลต่อจำนวนแถว
- แสดงข้อผิดพลาดพร้อมเลขแถว; ตรวจทุกแถวของชุดที่จะส่งออกก่อนเริ่มสร้างไฟล์
- ชุดละ 30 รายการ; ZIP / Print Sheet ส่งเฉพาะชุดที่กำลังดู
- PDF Preview ส่งเพียงรายการที่กำลังดู ไม่ใช่ทุกใบในชุด
- QTY เป็นจำนวนสินค้าบนฉลาก ไม่ใช่จำนวนสำเนา แต่ละแถวสร้าง 1 ใบ

## สิ่งที่เปลี่ยนจากเวอร์ชันเดิม

- แก้บรรทัดว่าง Batch, คอลัมน์ยาวไม่เท่ากัน และ Manual fallback ที่ทำให้หลายสินค้ามีบาร์โค้ดเดียวกัน

- แก้ชื่อ TH/EN ใน Batch และ SVG Outlined โหมด TH/EN

### ใช้ชิ้นงานจาก PDF กล่องใน Carton Studio

1. ใน Illustrator แยกโลโก้ สัญลักษณ์ บาร์โค้ด พื้นหลัง และไดไลน์ที่ต้องการเปิดปิดอิสระไว้คนละ Top-Level Layer แล้วบันทึก PDF โดยเปิด **Create Acrobat Layers from Top-Level Layers** เก็บภาพและฟอนต์ที่ต้องใช้ไว้ใน PDF
2. เปิด Carton Studio → แยกองค์ประกอบจาก PDF กล่อง → เลือกหน้า → เลือกเลเยอร์หรือวัตถุ ดูชนิดและรูปร่างบนพื้นตาราง แล้วเพิ่มแยกชิ้นหรือรวมเป็นชิ้นเดียว ทดลองได้กับ **examples/Carton-PDF-Layers.pdf**
3. ลากกรอบบนภาพตัวอย่างเมื่อต้องการครอป ภาพสแกนทั้งหน้าจะเป็นภาพชิ้นเดียว การครอปรักษาสีและพื้นในกรอบตามต้นฉบับ ลากชิ้นจากคลังลงแบบคลี่ ชิ้นที่ใหญ่กว่าแผงจะถูกย่อให้พอดี ขนาดกรอบอัตโนมัติประมาณจากขอบหมึกพร้อมเผื่อเล็กน้อย
4. ส่ง PDF เพื่อคงเส้น สี และทรัพยากร PDF ที่รองรับ การครอปเป็นการกำหนดขอบเขตที่แสดง ไม่ใช่การล้างข้อมูลลับ SVG ใช้ภาพโปร่งใสสำหรับส่วนที่มาจาก PDF ที่เป้าหมาย 600 ppi จำกัดด้านยาว 8,192 px และ 16 ล้านพิกเซลต่อชิ้น JPEG เป็นภาพเรนเดอร์สำหรับตรวจงาน
5. ตรวจแยกสีและ Overprint ในโปรแกรมพรีเพรสก่อนผลิต โดยเฉพาะเมื่อผสมไฟล์จากหลายโปรไฟล์สี ระบบยังไม่สร้างไฟล์ที่รับรอง PDF/X เค้าโครงบางชนิด เช่น PDF ล็อกรหัส กลุ่มแสดงผลตามเงื่อนไข หรือข้อความที่ใช้ตัดมาสก์ อาจต้องปรับไฟล์ต้นทางก่อนนำเข้า

### โหมดสีหมึกของ Carton Studio
เลือก **สีหมึกพิมพ์** เพื่อสลับสีต้นฉบับ หมึกดำ K หรือหมึกพิเศษชื่อ Carton Blue โหมดสีเดียวแปลงความสว่างเป็นน้ำหนักหมึกและให้สีขาวเห็นเนื้อกระดาษ ใช้ PDF สำหรับการแยกเพลต เส้นตัดและพับแสดงบนแบบคลี่และไม่รวมในไฟล์งานพิมพ์สีเดียว น้ำเงินบนจอเป็นสีจำลองสำหรับพรีวิว ควรระบุหมึกจริงกับโรงพิมพ์ตามตัวอย่างที่ตกลงกัน

## Sticker Studio

เปิด `index.html` แล้วเลือก **จัดแผ่นสติกเกอร์** ตัวอย่างแรกใช้ต้นแบบขนาดหลังตัด 50 × 30 มม. บนแผ่น 1,000 × 1,000 มม.

1. เตรียมต้นแบบหนึ่งดวงพร้อมพื้นที่ตัดตก งาน Illustrator ที่ต้องการเก็บสีพิเศษ ตัวอักษรไทย หรือรายละเอียดเล็ก แนะนำ PDF ขนาดจริงที่ฝังฟอนต์หรือแปลงตัวอักษรเป็น Outline แยกเลเยอร์ ARTWORK และ DIE CUT แล้วเปิดตัวเลือกเก็บ Acrobat Layers เมื่อบันทึก PDF เส้นตัดเป็นเวกเตอร์ Stroke ปิดวง ไม่มี Fill ไฟล์ AI อ่านเฉพาะส่วน PDF Compatible ที่บันทึกมาด้วย
2. เลือกหน้าต้นแบบ เลเยอร์สำหรับพิมพ์ และเลเยอร์เส้นตัด ตรวจหนึ่งดวงด้วย “ขยายดูกราฟิกและเส้นตัดหนึ่งดวง” หากไฟล์มีมาร์กหรือข้อความกำกับ ให้วางองค์ประกอบเหล่านั้นนอกเลเยอร์สำหรับพิมพ์ก่อนนำเข้า เส้นที่แปลงเป็นภาพจะต้องเตรียมเส้นเวกเตอร์เพิ่ม
3. SVG รองรับกราฟิกพื้นฐานแบบ Presentation Attributes ข้อความที่แปลงเป็นเส้น และภาพ PNG/JPG ฝังในไฟล์ วางเส้นตัดในกลุ่มที่มี id เป็น DIE_CUT สำหรับกราฟิกที่มีเอฟเฟ็กต์หรือ CSS ซับซ้อนให้ใช้ PDF สำหรับต้นแบบภาพ PNG/JPG ให้ระบุขนาดพิมพ์ กราฟิกจะจัดกึ่งกลางและครอปให้เต็มกรอบรวมตัดตก เลือกเส้นสี่เหลี่ยม มุมมน วงรี หรือแนบ SVG เส้นปิดบนอาร์ตบอร์ดเดียวกับกราฟิก
4. กรอกจำนวน เช่น 1,200 เลือกช่องไฟ ตัดตก และพื้นที่ขอบทั้งสี่ตามเครื่องจริง ระบบลองวางตารางแนวเดิมและหมุนทั้งแผ่น 90° แล้วแบ่งจำนวนลงแผ่นถัดไปตามจริง ระยะขอบเป็นพื้นที่เว้นว่างสำหรับหัวจับและมาร์กของ RIP ให้ซอฟต์แวร์เครื่องกำหนดมาร์กตามรุ่น
5. ใช้ **PDF พิมพ์–ตัด** สำหรับทุกแผ่น เลเยอร์ DIE CUT อยู่บน ARTWORK และใช้สี Spot แบบ Separation ค่าเริ่มต้น CutContour ปรับตัวสะกดและตัวพิมพ์เล็กใหญ่ตาม RIP ได้ รูปและเวกเตอร์เก็บครั้งเดียวแล้วเรียกใช้ซ้ำ ภาพพรีวิวไม่มีผลกับความคมของ PDF
6. **SVG** ส่งออกแผ่นที่เลือก พร้อมกราฟิกและเส้นตัดแยกกลุ่ม กราฟิกจาก PDF จะฝังเป็น PNG โดยตั้งเป้า 600 ppi และจำกัดด้านยาว 6,000 px เพื่อควบคุมหน่วยความจำ SVG ใช้สีแสดงแนวตัด เมื่อเปิดไปผลิตต่อให้กำหนด Spot ของเครื่องอีกครั้ง **JPG** เป็นพรีวิว 2,000 × 2,000 px ของแผ่นที่เลือก เปิดหรือปิดเส้นตัดก่อนส่งภาพได้
7. ทดสอบเครื่องครั้งแรกด้วย PDF จากต้นแบบตัวอย่างจำนวน 1 ดวง นำเข้า RIP ที่สเกล 100% ตรวจว่ามีแนวตัดหนึ่งวง ขนาด 50 × 30 มม. และพิมพ์–ตัดบนวัสดุจริงเพื่อวัดระยะเหลื่อม ก่อนใช้กับยอดผลิตทั้งหมด


### ส่งงานเมื่อแยกเครื่องพิมพ์และเครื่องตัด

กด **แยกไฟล์พิมพ์และตัด (ZIP) · ทุกแผ่น** ครั้งเดียว จะได้ PDF สองไฟล์ที่ตั้งชื่อตามงาน ไฟล์ลงท้าย `_Print.pdf` มีเลเยอร์ ARTWORK พร้อมกราฟิกและตัดตก ไฟล์ลงท้าย `_Cut.pdf` มีเลเยอร์ DIE CUT พร้อมเส้นเวกเตอร์และชื่อ Spot ที่ตั้งไว้ ทั้งสองไฟล์ใช้หน้า 1,000 × 1,000 มม. เท่ากันทุกหน้า ตั้งแต่ดวงแรกจนถึงแผ่นสุดท้ายที่วางไม่เต็ม

จับคู่หน้าเลขเดียวกันของสองไฟล์ ตั้งสเกล 100% ใช้จุดเริ่มและทิศทางป้อนวัสดุเดียวกัน ปิดการครอปตามขอบกราฟิกและการจัดกึ่งกลางอัตโนมัติเมื่อนำเข้า ให้ RIP หรือซอฟต์แวร์เครื่องตัดสร้างมาร์กลงทะเบียนตามรุ่นเครื่องก่อนพิมพ์ ตำแหน่งตามไฟล์เป็นพิกัดออกแบบ ส่วนความคลาดเคลื่อนจากการป้อนวัสดุตรวจได้ด้วยชุดทดสอบ `examples/Sticker-RIP-Test-Print-Cut.zip` ข้างในมีต้นแบบหนึ่งดวง ขนาดหลังตัด 50 × 30 มม.
